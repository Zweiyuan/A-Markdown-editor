# A-Markdown-editor: mdedit
A lightweight Markdown editor.

**mdedit** 是一款轻量级 Markdown 阅读与编辑软件，适用于 Windows 系统。

## 主要功能

- Markdown 实时编辑与预览
- 支持 LaTeX 数学公式
- 支持打开、保存和另存为 Markdown 文件
- 支持拖放打开 `.md` 文件
- 支持粗体、斜体和公式快速插入
- 自动保存恢复草稿
- 支持桌面及窄屏布局

## 数学公式

行内公式：

```latex
$E=mc^2$
```

块级公式：

```latex
$$
\int_{-\infty}^{\infty}e^{-x^2}\,dx=\sqrt{\pi}
$$
```

## 软件特色

- 体积小巧，约 11.4 MB
- 免安装，双击 `mdedit.exe` 即可运行
- 无需安装 Python
- 界面简洁，编辑与预览分栏显示
- 可关联 `.md` 和 `.markdown` 文件
- 支持中文及 UTF-8 编码

## 使用方法

1. 双击 `mdedit.exe` 启动软件。
2. 在左侧输入 Markdown，右侧查看实时预览。
3. 使用工具栏打开或保存文件。
4. 也可以将 Markdown 文件拖到 `mdedit.exe` 上直接打开。

如需双击 `.md` 文件直接进入 mdedit，请运行 `associate-md.cmd`，或在 Windows“打开方式”中选择 `mdedit.exe`。

## 运行要求

- Windows 10 或 Windows 11
- Microsoft Edge WebView2 Runtime (多数 Windows 10/11 已自带)
- Markdown 和公式预览目前需要连接网络
